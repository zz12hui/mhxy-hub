# 梦幻西游跑环大全

单页 Web 应用，聚合宠环助手（100 环）和跑环助手（300 环）两个工具。纯静态 HTML + CSS + Vanilla JS，零依赖。

## 设计风格

深色背景 + 径向渐变光斑 + 玻璃卡片 + 悬停发光效果（参考 DeepSeek 首页风格）。CSS 变量管理主题色。

## 快速开始

```bash
cd "/Volumes/data 1/local/dev"
python3 -m http.server 8080
# 访问 http://localhost:8080/mhxy-hub/
```

## 功能模块

- **Hub 首页** — 工具导航入口 + 知识库入口
- **宠环助手（100 环）** — 记录/预测/控分/历史/统计（5 个标签页）
- **跑环助手（300 环）** — 记录/奖励/历史/统计（4 个标签页）
- **操作指南** — 分步引导弹窗（支持键盘 ← → 导航）
- **知识库** — 4 分类 FAQ（宠环技巧、跑环攻略、物价参考、常见问题）
- **首次访问欢迎页** — localStorage 标记，仅显示一次

## 特色功能

- 多角色数据隔离（localStorage 按用户 ID 存储）
- Canvas 分数趋势图
- 单环编辑 + 批量填充（Canvas 滑块）
- 实时时钟 + 费用计算
- 响应式设计（768px / 400px 两个断点）
